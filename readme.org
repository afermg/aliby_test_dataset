#+TITLE: Generating a small test dataset for aliby
#+AUTHOR: Alán F. Muñoz

* Overview

This repository is an LLM-aided effort to generate a small, reproducible dataset for integration testing the [[https://github.com/afermg/aliby][aliby]] software framework. 

The original full-size images were obtained from the JUMP_lite dataset. This project contains the logic to:
1. Crop those full-size images into smaller 256x256 test patches.
2. Group the resulting TIFF channels into a single `zarr` array using `zstd` compression via the provided Python script.
3. Package the outputs into a single `.tar.gz` archive suitable for integration testing.
4. Upload the dataset directly to Zenodo to act as an external test artifact for CI workflows.

* Reduce the size of the images
#+begin_src sh
  cd data && mkdir -p tif_256 && for file in tif_1080/*.tif; do filename=$(basename "$file"); magick "$file" -gravity center -crop 256x256+0+0 +repage "tif_256/$filename"; done && cd ..
  for i in data/tif_*/*; do ls $i; done
#+end_src
